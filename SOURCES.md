# Fuentes y notas de atribución

Este curso está escrito de forma independiente. Las fuentes siguientes permiten comprobar afirmaciones o profundizar; no implican afiliación, aval ni reproducción de contenido.

## Hechos históricos y técnicos

- McCulloch, W. S. y Pitts, W. (1943), *A Logical Calculus of the Ideas Immanent in Nervous Activity*. https://doi.org/10.1007/BF02478259
- Turing, A. M. (1950), *Computing Machinery and Intelligence*, *Mind*. https://academic.oup.com/mind/article/LIX/236/433/986238
- McCarthy, J. et al. (1955), propuesta Dartmouth; reunión de verano de 1956. https://www-formal.stanford.edu/jmc/history/dartmouth/dartmouth.html
- Vaswani et al. (2017), *Attention Is All You Need*. https://arxiv.org/abs/1706.03762
- Yao et al. (2022), *ReAct: Synergizing Reasoning and Acting in Language Models*. https://arxiv.org/abs/2210.03629
- Model Context Protocol. https://modelcontextprotocol.io

## Convenciones del ecosistema

- Gentle AI: documentación de uso y convenciones ODD/RDD. https://github.com/Gentleman-Programming/gentle-ai (consulte `docs/usage.md`; la rama principal puede incluir cambios no publicados).
- Gentle Shell: README oficial, descrito como shell de desarrollo controlado y nativo de Pi. https://github.com/Gentleman-Programming/gentle-shell
- Engram: README oficial, descrito como memoria persistente agnóstica al agente. https://github.com/Gentleman-Programming/engram

Las descripciones se mantienen deliberadamente conservadoras: esta presentación no afirma versiones, comandos instalados ni permisos que las fuentes no documenten.

## Lectura pública complementaria

- *The Amazing Gentleman Programming Book*, capítulo 20, “De Token a Agente”. https://the-amazing-gentleman-programming-book.vercel.app/es/book/Chapter20_From-Token-to-Agent

El enlace es una referencia de lectura pública y una base temática: el curso no copia su prosa, código ni ilustraciones. El capítulo articula modelo, inferencia, contexto, harness, conocimiento, patrones y proceso; no atribuye ODD ni RDD. El responsable editorial y los derechos/licencia del libro siguen **pendientes** de confirmación antes de reutilizar cualquier material atribuible.

## Preparación para publicación

Antes de publicación, un responsable debe volver a verificar enlaces, fechas, licencia y atribuciones, y añadir la URL de despliegue solo cuando exista una confirmada. No hay propietario ni destino remoto inventados en este repositorio.
